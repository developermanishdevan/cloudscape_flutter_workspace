# cs_catalog

The Cloudscape for Flutter component catalog: every component built so far,
with its live previews, the API generated from its dartdoc, and a link to the
matching Cloudscape guideline page. Built only with `cloudscape_flutter`
widgets (no Material, so no Widgetbook).

```bash
cd apps/catalog
flutter run -d chrome     # or: -d macos
flutter test              # every page × light/dark × comfortable/compact × LTR/RTL
```

- The top bar switches color mode, density and the previews' reading
  direction for every page at once.
- Page data lives in `lib/src/generated/catalog_data.g.dart`, generated by
  `tool/catalog_gen` (`dart run melos run catalog:generate`). Never edit it
  by hand; `catalog:check` in `verify` fails when it is stale.
- To add a page: add an entry to `tool/catalog_gen/lib/src/manifest.dart`
  and regenerate. See `docs/DEVELOPMENT_GUIDE.md` §5.4.
